## Descripción

**We Got Kicks** es una tienda online de sneakers y streetwear inspirada en plataformas como StockX. El proyecto incluye una página principal con catálogo de productos, buscador, filtros, carrusel de ofertas, sistema de favoritos, formulario de login y contacto. Está desarrollado como práctica de trabajo colaborativo con Git y GitHub.

## Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)

## Funcionalidades

- **Catálogo de productos** con 25 sneakers y ropa de marcas como Nike, Supreme, Off White y Valley.
- **Buscador y filtros** por categoría, género y marca.
- **Sistema de favoritos** con persistencia en `localStorage`.
- **Carrusel automático** de ofertas con indicadores navegables.
- **Formulario de login** con validación de campos (mayorista / minorista).
- **Formulario de contacto** con validación y mensajes de éxito/error.
- **Botón volver arriba** y **toasts** de notificaciones.
- **Diseño responsive** adaptado a móviles y tablets.
- **Nuevos lanzamientos** en sección con scroll horizontal.
